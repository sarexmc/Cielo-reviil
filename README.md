# Dedsafio (Forge 1.20.1)
Comandos (nivel de operador): `/dedsafio sky` (cielo rojo), `/dedsafio sky off`,
`/dedsafio start vertical|horizontal` (la grieta aparece ~90 bloques delante de ti, en lo alto), `/dedsafio stop`.
El mod debe estar instalado en el servidor y en todos los clientes.

## Obtener el .jar
1. Crea un repo en GitHub y sube TODO el contenido de esta carpeta (incluida `.github`).
2. Pestaña **Actions** > "Build mod" > último run > **Artifacts** > `dedsafio-jar`.
3. Descomprime y pon `dedsafio-1.0.0.jar` en `mods/` (Forge 1.20.1).
